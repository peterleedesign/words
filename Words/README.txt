말씀의 길 PWA 준비 파일

구성
- index.html, manifest.webmanifest, service-worker.js
- icons/icon-192.png, icons/icon-512.png, icons/apple-touch-icon.png (반드시 icons 폴더째로 함께 올리세요)

설치 준비
1. 폴더 안의 파일과 icons 폴더 전체를 HTTPS를 지원하는 정적 웹 호스팅에 올립니다.
2. 사이트 주소를 Android Chrome 또는 iPhone Safari에서 엽니다.
3. Android Chrome은 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
4. iPhone Safari는 공유 버튼을 누르고 '홈 화면에 추가'를 선택합니다.

업데이트
- index.html을 수정해 다시 올리면, 다음 온라인 실행/새로고침에서 변경사항을 불러옵니다. 오프라인일 때는 마지막으로 캐시된 화면을 엽니다.
- 아이콘이나 service-worker.js의 파일 목록을 바꿨다면 service-worker.js 맨 위 CACHE_NAME(bible-path-v4)의 숫자를 올려 주세요.
- iPhone은 상태 표시줄 설정을 '홈 화면에 추가'할 때 한 번만 읽습니다. 이전 버전을 이미 추가해 두었다면 삭제 후 다시 추가해야 새 설정이 적용됩니다.

사용법
- 장 번호를 누르면 체크/해제됩니다.
- 여러 장은 번호를 꾹 누른 채 옆으로 쓸어서 한 번에 체크할 수 있고, 이미 모두 읽은 구간을 같은 방식으로 쓸면 한 번에 해제됩니다. (꾹 누르지 않고 바로 밀면 일반 스크롤입니다.)

읽기 기록
체크 기록은 현재 브라우저/기기에 저장됩니다. 계정 동기화는 포함하지 않았습니다. 브라우저의 사이트 데이터를 지우면 기록도 함께 지워집니다.

추가 기능
- 홈의 '이어 읽기' 버튼: 마지막으로 체크한 곳 다음 장으로 바로 이동합니다.
- '기록 백업 저장 / 백업 불러오기': 기록을 파일로 저장하고, 불러오면 현재 기록과 합쳐집니다. 폰을 바꾸거나 사이트 데이터를 지우기 전에 한 번씩 저장해 두세요.
- 여러 장을 쓸어 체크/해제하면 '되돌리기' 버튼이 잠깐 나타납니다.
- 새 버전이 배포되면 '새로고침' 안내가 뜹니다. (service-worker.js의 CACHE_NAME 숫자를 올려야 알림이 뜹니다.)
